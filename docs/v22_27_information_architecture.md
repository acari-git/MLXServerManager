# v22.27.0 Information Architecture Alignment

v22.27.0 aligns the integrated workspace around the four primary user jobs: Models, Downloads, Logs, and Settings.

## Changes

- Added a workspace overview strip above the model table.
- Made Models, Downloads, Logs, and Settings visible as equal top-level work areas from the main workspace.
- Added status details to each overview card so the user can understand what each area currently contains before navigating.
- Clarified the right inspector panel order and purpose.
- Updated the integrated footer version label to 22.27.0.

## Verification

- The previous v22.26.0 Debug build passed before this visual organization pass.

## Direct Mode

Direct Mode remains unchanged. The overview strip and inspector text are navigation and explanation only; they do not touch request flow or model serving.
